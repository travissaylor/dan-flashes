# Dan Flashes

An in-universe e-commerce marketplace for Dan Flashes, the fictional shirt store from *I Think You Should Leave*. Users compose layered patterns in a visual designer, list the resulting one-of-one shirts for sale, and trade them in a fake currency called Bones. The more complicated the pattern, the more it costs.

[PROJECT.md](PROJECT.md) describes the product, the economy, and the architecture decisions behind them.

## Run it locally

```sh
npm install
npm run dev
```

The app starts on http://localhost:3000. With no environment configured, public pages read from a small development catalog in `src/data/mock-repository.server.ts`, so browsing works immediately. Anything that needs an account fails with a configuration error until Supabase is set up.

To sign in, buy, sell, or save a shirt, copy `.env.example` to `.env.local` and follow [SUPABASE.md](SUPABASE.md). That guide covers both a hosted project and a local Supabase stack.

## Layout

| Path | Contents |
| --- | --- |
| `src/routes` | File-based TanStack Router routes and their loaders |
| `src/server` | Server functions for authenticated reads and mutations |
| `src/data` | The marketplace repository interface and its Supabase and development adapters |
| `src/lib` | Domain logic with no I/O: patterns, complexity, pricing, economy constants, input contracts |
| `src/components` | React components shared across routes |
| `src/styles` | Per-route stylesheets |
| `supabase/migrations` | Versioned SQL: schema, row-level security, views, and the economy RPCs |

`src/routeTree.gen.ts` is generated by the router plugin. Do not edit it by hand.

Unit tests sit next to the modules they cover, as `src/lib/*.test.ts`.

## Two rules worth knowing before you edit

**Pattern JSON is the source of truth.** A shirt is a structured pattern definition. The browser previews it as SVG, the server re-validates it before saving, and `/shirts/<id>/image.png` rasterizes it on demand. Patterns are immutable once saved.

**The database owns the economy.** Balances, fees, rewards, and purchases run through PostgreSQL RPCs that check `auth.uid()` and lock the rows they touch. The constants in `src/lib/economy.ts` exist for display and tests only. Changing a number there changes what the site says, not what it charges.

## Deploying

The site deploys to Netlify from Git using the build in `netlify.toml`. Set the same variables from `.env.example` in the Netlify environment, then add the deployed origin to the Supabase auth redirect allow list as described in [SUPABASE.md](SUPABASE.md).
